DevSecOps Job Hub — How It’s Built

A FastAPI + SQLModel job aggregator targeting early-career cleared cloud-security roles — containerized with Podman for local and production runs.

Overview

DevSecOps Job Hub is a Python web application that aggregates job postings for cleared cloud-security and DevSecOps roles at U.S. government contractors. The backend is FastAPI serving Jinja2 HTML templates, with SQLite as the database and SQLModel as the ORM layer that bridges FastAPI’s Pydantic validation with SQLAlchemy’s query engine. Jobs are seeded from curated companies, scraped from ATS APIs, and filtered to only show entry-level and mid-level postings — senior roles are excluded at ingest. The entire stack runs locally with uvicorn and ships as a Podman container for deployment.

Tech Stack

Python 3.12 FastAPI SQLModel SQLite Podman Jinja2
  • Python 3.12+ — full type hints throughout; the newer generic syntax (list[dict], int | None) keeps models readable and mypy strict.
  • FastAPI — async-ready HTTP framework; route parameters are typed with Pydantic models, so bad query strings return a 422 automatically. The auto-generated /docs UI is the primary developer interface.
  • SQLModel — sits between Pydantic and SQLAlchemy; a single class definition doubles as an API schema and a database table, eliminating the usual ORM/schema duplication.
  • SQLite — one file (jobs.db); no server to manage. The engine is created once in db.py and injected into routes via FastAPI’s Depends() pattern.
  • Podman — rootless container runtime used in place of Docker. The multi-stage Containerfile keeps the runtime image small by leaving build tooling in a throwaway builder stage.
  • Jinja2 — templating engine for server-rendered HTML. Custom filters handle currency formatting and GS-grade inference directly in templates.

How Each Part Works

src/devsecops_job_hub/models.py — SQLModel data models

SQLModel classes define both the database schema and the shape of data flowing through the app. Setting table=True tells SQLModel to create a real database table from this class. Enum fields like ClearanceLevel are stored as strings in SQLite and validated automatically by FastAPI when they appear in query parameters.

class Job(SQLModel, table=True):
    id: int | None = Field(default=None, primary_key=True)
    company_id: int = Field(foreign_key="company.id", index=True)
    title: str
    role_family: RoleFamily | None = Field(default=None, index=True)
    career_stage: CareerStage | None = Field(default=None, index=True)
    clearance_required: ClearanceLevel = Field(
        default=ClearanceLevel.NONE, index=True
    )
    clearance_sponsorship_available: bool = False
    remote_eligible: RemoteEligibility = Field(
        default=RemoteEligibility.ONSITE, index=True
    )
    salary_min: int | None = None
    salary_max: int | None = None
    apply_url: str = Field(index=True)
    posted_at: datetime | None = None
    last_seen_at: datetime = Field(default_factory=_utcnow)
    is_active: bool = Field(default=True, index=True)

src/devsecops_job_hub/main.py — FastAPI GET route with filter chain

The root route builds a SQLModel select() statement and chains .where() clauses based on which query parameters are present. FastAPI automatically parses and validates each parameter against its declared type; empty strings from HTML form submissions are coerced to None by a BeforeValidator so the route never 422s on an empty dropdown.

@app.get("/", response_class=HTMLResponse)
def index(
    request: Request,
    session: Annotated[Session, Depends(get_session)],
    role: list[RoleFamily] | None = Query(default=None),
    stage: _OptStage = None,
    clearance: _OptClearance = None,
    remote: _OptRemote = None,
    min_salary: _OptInt = None,
    fit_only: bool = False,
) -> HTMLResponse:
    stmt = select(Job, Company).join(Company).where(Job.is_active)
    if role:
        stmt = stmt.where(Job.role_family.in_(role))
    if stage:
        stmt = stmt.where(Job.career_stage == stage)
    if clearance:
        stmt = stmt.where(Job.clearance_required == clearance)
    if min_salary:
        stmt = stmt.where(Job.salary_min >= min_salary)
    db_rows = session.exec(stmt).all()
    return templates.TemplateResponse(request, "jobs.html", {...})

Containerfile — Multi-stage Podman build

A two-stage build: the builder stage installs build tooling and pip-installs the package into /install; the runtime stage starts from a clean Python slim image, copies only /install, and runs as a non-root user. A HEALTHCHECK probes /healthz so an orchestrator knows when the app is ready.

FROM python:3.12-slim AS builder
WORKDIR /build
RUN apt-get update \
 && apt-get install -y --no-install-recommends build-essential \
 && rm -rf /var/lib/apt/lists/*
COPY pyproject.toml ./
COPY src ./src
RUN pip install --no-cache-dir --prefix=/install .

FROM python:3.12-slim AS runtime
RUN groupadd -r app && useradd -r -g app -m -s /sbin/nologin app
COPY --from=builder /install /usr/local
WORKDIR /app
USER app
EXPOSE 8000
HEALTHCHECK --interval=30s --timeout=5s --start-period=15s --retries=3 \
    CMD python -c "import urllib.request,sys; \
        r=urllib.request.urlopen('http://localhost:8000/healthz',timeout=3); \
        sys.exit(0 if r.status==200 else 1)"
ENTRYPOINT ["uvicorn", "devsecops_job_hub.main:app", \
            "--host", "0.0.0.0", "--port", "8000"]

pyproject.toml — Project metadata and tooling config

A single pyproject.toml replaces setup.py and tool-specific config files. It declares runtime dependencies (FastAPI, SQLModel, uvicorn, httpx, APScheduler, OpenTelemetry), dev dependencies (pytest, ruff, mypy, bandit), and the setuptools.packages.find entry pointing at the src/ layout so the package installs cleanly in both editable and containerized modes.

Replicate It Yourself

  1. Install the core stack: pip install fastapi sqlmodel uvicorn[standard] jinja2
  2. Define your SQLModel classes with table=True. Call SQLModel.metadata.create_all(engine) once on startup to create tables — SQLModel infers column types from Python type annotations.
  3. Create a database engine and session factory in db.py: engine = create_engine("sqlite:///jobs.db"). Use Depends(get_session) to inject a Session into each route — FastAPI handles teardown automatically.
  4. Write your GET route using select(MyModel).where(...) and chain .where() calls conditionally on the presence of each query parameter. Return a TemplateResponse with the results as template context.
  5. Run locally: uvicorn myapp.main:app --reload. Visit http://localhost:8000/docs for the auto-generated API explorer.
  6. Write a two-stage Containerfile: builder stage installs deps, runtime stage copies only the installed packages. Add a HEALTHCHECK on your /healthz route.
  7. Build and run with Podman: podman build -t myhub:dev . then podman run --rm -p 8000:8000 myhub:dev. Rootless by default — no root daemon required.
